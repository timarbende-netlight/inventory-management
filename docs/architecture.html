Overview

A demo single-page application for tracking inventory, orders, demand, spending, and reports.

A Vue 3 single-page app (port 3000) calls a FastAPI REST backend (port 8001). The backend has no database: JSON files in server/data/ are loaded into Python lists once at startup and filtered in memory on every request. Four global filters (time period, warehouse, category, order status) are shared by all views and sent as query parameters.

System Architecture

Three tiers, all running locally. Browser to API over HTTP/JSON; API to data via startup file load.

Data Flow

What happens when a user changes a filter.

  1. User selects a filter in FilterBar.vue. The value is written to a shared singleton ref in useFilters.js (period, warehouse, category, status).
  2. The active view reacts. A watcher on the filter refs calls getCurrentFilters(), which maps the period to a month parameter.
  3. api.js builds the request. Filters set to all are omitted; the rest become query params, e.g. /api/orders?warehouse=Tokyo&month=Q2-2025.
  4. FastAPI routes the request and calls apply_filters() (warehouse, category, status) and filter_by_month() (month or quarter prefix match on order_date) against the in-memory lists.
  5. Pydantic validates the response against the declared response_model and FastAPI serializes it to JSON.
  6. The view stores raw data in refs (allOrders, inventoryItems) and derives totals, chart series, and table rows with computed properties, which re-render the UI.

Observations

Gaps found while reading the code. Worth knowing before building on top of it.

Frontend calls endpoints the backend does not implement

  • api.js defines getTasks, createTask, toggleTask, deleteTask (/api/tasks) and createPurchaseOrder, getPurchaseOrderByBacklogItem (/api/purchase-orders).
  • main.py has no routes for these. It defines PurchaseOrder models and loads purchase_orders.json, but exposes no endpoint. The backend has no POST, PATCH, or DELETE routes at all.

Backlog view is not routed

  • views/Backlog.vue exists but is not registered in main.js. Backlog data reaches the UI through the Dashboard and its detail modal.

Other

  • The API base URL (http://localhost:8001/api) is hard-coded in api.js and again in Reports.vue.
  • CORS allows all origins; acceptable for a local demo only.
  • Data is loaded once at startup, so any change to the JSON files requires a backend restart.
  • Quarterly mapping is duplicated: a QUARTER_MAP dict for filtering and an if/elif chain in /api/reports/quarterly.
